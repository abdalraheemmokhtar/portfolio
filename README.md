A focused portfolio for AI product engineering, data, full-stack systems, and interactive software.

- [RDBMDS](https://github.com/abdalraheemmokhtar/RDBMDS) — database-management-system experiment in C.

## Run locally

This is a dependency-light static site. Open `index.html` directly, or serve the directory with any static web server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Publishing

The site is designed for GitHub Pages:

`https://abdalraheemmokhtar.github.io/portfolio/`

The root `index.html` and `style.css` are the source of truth. The older `dist/` bundle is retained for historical reference and is not used by the current page.
